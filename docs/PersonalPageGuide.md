# 个人页面指南

个人页面功能暂未开放，一下为当前设计。

## 创建方式

1. 将 `site/members/template/` 复制为 `site/members/<github-id>/`。
2. 使用英文小写 GitHub ID 作为目录名。
3. 修改页面内容，并将根节点类名改为唯一的 `member-<github-id>`。
4. 如需局部样式，在自己的目录内创建 CSS 文件，且所有选择器必须限定在个人页面根节点下。
5. 运行 `npm test` 后提交 Pull Request。

## 最低内容

- 经本人确认的姓名或昵称。
- 一句话介绍。
- 参与的赛事部工作。
- 兴趣方向。
- 可选的公开作品或链接。

照片、实名和外部链接均为自愿项。

## 禁止内容

- 手机号、学号、住址、私人邮箱等敏感信息。
- 第三方跟踪脚本、`iframe`、自动播放媒体或远程 JavaScript。
- 修改公共导航、页脚或全局 `body` 样式的个人 CSS。
- 未经授权的图片、字体或其他素材。
