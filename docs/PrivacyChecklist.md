# 隐私与公开内容检查清单

合并公开内容前逐项确认：

- [ ] 赛事事实、结果和获奖记录具有可靠的公开来源。
- [ ] 姓名、昵称、照片、介绍和个人链接已经本人确认。
- [ ] 不包含手机号、私人邮箱、学号、住址或身份证明信息。
- [ ] 不包含报名表、签到表、准入码、缺考记录或未公开排名。
- [ ] 不包含奖金、报销单据或其他财务材料。
- [ ] 不包含密码、令牌、密钥、连接串或管理员账号。
- [ ] 图片已经获得授权、完成压缩并设置替代文本。
- [ ] 外部链接是必要且可信的，不包含跟踪参数。
- [ ] 已说明内容更正和删除的联系途径。

无法确认是否可公开时，不提交到仓库，交由内容负责人复核。
